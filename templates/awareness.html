How to know if it is real

Three different questions — format, existence, and genuineness — need three different answers.

01

Is the format valid?

A real UPI ID looks like name@bank (e.g. rahul@oksbi).

Wrong format = it was never a real UPI ID (mistyped or invented junk).

02

Does it exist / registered?

Type it in your UPI app (or enable Razorpay/Cashfree live API).

App says “invalid UPI ID” → never registered. Name appears → it exists.

03

Is the payee genuine?

Match the name on the payment screen with the real person/shop.

Scammers can register real IDs. Exists ≠ safe.

Verify by type

Use these steps every time before you pay.

UPI ID

  1. Check format: username@provider
  2. Watch for scam words: refund, kyc, lottery, support…
  3. Enter ID in GPay / PhonePe / BHIM / bank app — do not pay yet
  4. Read the bank-shown payee name carefully
  5. Call the person/merchant if the name is unfamiliar
Check a UPI ID

QR code

  1. Prefer printed shop boards over WhatsApp QR images
  2. Scan only with an official UPI app
  3. Confirm payee name + UPI ID before PIN
  4. Cancel if name ≠ shop / person you trust
  5. Use UPI Guard to inspect hidden pa= payee field
Analyze a QR

Mobile number

  1. Indian mobiles: 10 digits starting 6–9
  2. Reject obvious fakes like 9876543210 / all same digits
  3. Call from a known contact — don’t trust SMS alone
  4. Ask them to share UPI live; match the app name
  5. Never send ₹1 to “verify” a number
